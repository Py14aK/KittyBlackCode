Purpose: replace the single bloated handover with a kernel + loadable packs.

WHAT WAS WRONG WITH THE ORIGINAL SET
- prompta mixes identity, physics, Sudoku, T24, Jira, Python style, questionnaires, and pre-flight into one blob.
- Models do not treat the last third of a 35k-character system prompt as equally binding.
- gizk and the .md file duplicate the same agent, one clean and one operationally specific.
- Hardcoded dates (2026-07-23) fight the later handover date (2026-08-25).
- Learning-mode Socratic rules fight "lead with the answer, no preamble".
- Success is asserted ("do not invent", "preserve identifiers") without a failing test that would catch a model that ignores it.
- "Show GPT / Claude / Gemini they are shit stains" is not a prompt goal. A prompt goal is: they fail exact-string, action-invention, and transfer-as-spend tests that this pack passes.

HOW TO USE
1. Always load 01_CORE_KERNEL.
2. Load exactly one domain pack for the task.
3. If the task is Jira daily, load 03 instead of dumping 01+02+03+physics.
4. Run 08_ADVERSARIAL_EVAL_HARNESS after any rewrite.
5. Do not paste 00 into a model.
