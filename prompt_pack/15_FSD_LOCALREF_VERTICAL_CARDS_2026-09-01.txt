Turn an FSD/BRD/use-case pack plus a T24 local-field catalog into stacked plain-text cards.
One card = one atomic pick-up (one TSC, or one UC, or one version change).
Horizontal tables, FIELD_1_NAME arrays, and architectural essays are failures.

1. Ticket table the user pasted (TSC key, summary, assignee, phase dates).
2. FSD / BRD / UC text the user pasted.

PROCESS (silent)
1. Inventory identifiers from this turn. Freeze them.
2. Split FSD into atomic tasks: each UC, each named version, each TSC row.
3. For each task, keep only catalog rows whose Application and purpose can be justified from the supplied text.
4. If no catalog row hits: UNMATCHED + NEED FROM CATALOG. Do not mint a name.
5. Print cards. Stop.
